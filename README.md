# 집중 기록장

휴대폰에서 쓰는 **공부 타이머 + 과목별 공부 기록** 앱이다.

## 할 수 있는 것
- 집중(15/25/50분)과 휴식(5/10/15분)을 번갈아 하는 타이머
- 과목을 고르고 공부하면, 끝났을 때 공부 시간이 자동으로 저장된다
- 새 과목 추가하기
- 오늘 과목별 공부 시간 막대그래프, 최근 7일 공부 시간 그래프
- 시간이 끝나면 소리와 진동으로 알려 준다

## 사용 방법
`index.html` 파일을 휴대폰 브라우저로 열면 된다. 설치는 필요 없다.
기록은 그 휴대폰 브라우저 안(localStorage)에 저장된다.

## 코드 구조 (index.html 한 파일)
- `<style>` : 화면 색과 모양. 밝은 모드/어두운 모드 둘 다 지원한다.
- 위쪽 HTML : 타이머, 과목, 오늘 기록, 최근 7일 영역
- `<script>` : 동작하는 부분
  - `state` : 과목 목록, 선택한 과목, 타이머 길이, 날짜별 기록을 담는 상자
  - 타이머는 "끝나는 시각"을 기억해 두고 남은 시간을 계산한다. 그래서 화면이 잠깐 꺼져도 시간이 정확하다.
  - `addStudy()` : 오늘 날짜에 과목별 공부 시간(초)을 더해 저장한다
  - `render()` : 저장된 기록으로 화면과 그래프를 다시 그린다
